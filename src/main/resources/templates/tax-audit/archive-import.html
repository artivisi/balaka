Format ZIP

Akar ZIP berisi manifest.csv (UTF-8, dipisah koma, baris pertama nama kolom) dan file-file yang disebut di dalamnya. File boleh di dalam folder; kolom file berisi jalurnya, mis. 2023/faktur/010-23-00000001.pdf.

Kolom wajib: file. Kolom opsional: doc_number.

Nilai type: FAKTUR_PAJAK. Nilai source: BANK.

Satu baris yang salah menolak seluruh impor; semua kesalahan ditampilkan dan tidak ada dokumen yang disimpan.
